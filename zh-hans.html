隐私政策

音乐留在你的设备上。隐私说明，也应当清楚易读。

更新及生效日期：2026-10-28

无需注册账户。开发者不通过应用收集或上传你的曲库和播放记录。

适用范围

本政策适用于折页音乐（Sleeve Player）的 iOS 版本。该应用是一款本地音乐播放器，由Sleeve Player 开发者开发和维护。本政策不适用于 Android 版本或第三方服务。

在设备上处理的信息

为实现播放和管理曲库，应用会在设备上读取或保存以下信息：

信息用途
音乐文件和标签读取用户选定的音频文件、文件名和路径、歌名、歌手、专辑、时长、封面及音频技术参数，用于扫描、展示和播放。
本地歌词读取同名 LRC 文件或音频内嵌歌词，用于显示歌词和同步进度。不提供在线歌词检索。
播放及管理数据保存歌单、收藏、队列、播放位置、播放次数、最近播放时间和近期播放记录，用于恢复播放及生成智能列表。
偏好、授权和缓存保存外观、音效、睡眠定时、歌词偏移、排除目录、授权目录书签，以及曲库索引和音频分析缓存。

上述信息不由开发者通过应用上传至自有服务器，也不用于广告或跨应用跟踪。播放统计是在本机计算的功能数据，不是发送给开发者的使用分析。

文件访问与系统服务

应用通过系统文件或文件夹选择器访问你选择的音乐，并保存安全作用域书签，以便后续继续访问。你可以在应用的音乐文件夹管理中移除已授权目录；移除目录授权不会自动删除该目录中的原始文件。

应用使用后台音频能力继续播放，并向系统“正在播放”、锁屏和媒体控制界面提供当前歌曲信息、封面和播放进度。不请求相机、麦克风、定位或通讯录权限。

联网、共享与第三方

当前 iOS 版本不包含在线歌词请求、开发者自建云端曲库、广告、跟踪或第三方统计 SDK。应用不向开发者或广告服务自动发送曲库和播放记录。

若你选择 iCloud Drive 或其他文件提供商中的音乐，iOS 或文件提供商可能按需下载文件或同步相关数据，这由你的系统设置及提供商政策决定。设备备份也可能包含应用数据。本政策不表示系统服务永远不会使用网络。

你主动使用分享功能时，所选文件会交给你选择的接收应用或服务。使用文件删除功能可能删除你选定的原始音频，请在操作前确认。

保存期限、删除与控制

应用的设置、索引、缓存、歌单及播放记录保存在设备的应用数据区域，以支持持续使用。近期播放记录在新增记录时按最近 90 天、每首歌最多 200 条整理；累计次数和最近播放时间会继续保留。

你可以在应用内编辑歌单、管理目录及修改设置。选择“删除 App”可移除设备上的应用及其本地数据；“卸载 App”会保留文稿和数据。外部授权目录中的音乐、你已分享的副本以及 iCloud 或其他备份不会因此全部删除，请在相应服务中另行管理。

开发者无法远程访问或代为删除仅保存在你设备上的曲库与播放数据。

联系开发者时的信息

若你主动通过电子邮件联系开发者，你的邮箱地址、消息及自愿提供的截图或诊断信息会用于回复、排查问题或处理隐私请求。请不要发送不必要的个人信息或音乐文件。支持往来仅在处理请求及必要后续事项所需的期限内保留；你可以请求删除相关往来，但依法需要保留的信息除外。

访问本政策网页

本网页由 GitHub Pages 托管，不嵌入广告、分析脚本、第三方字体或开发者设置的跟踪 Cookie。页面内容不需要登录即可阅读。

访问网页时，GitHub 作为托管服务商会按其政策处理必要的访问数据（例如 IP 地址）。这与应用在设备上处理音乐数据不同。详情请参阅 GitHub 隐私声明。

儿童隐私

应用不通过账户注册或分析服务收集儿童个人信息，也不以收集儿童信息为目的。如你认为主动发送的支持信息涉及儿童个人信息，请联系开发者处理。

政策更新

功能或数据处理方式发生变化时，本政策会相应更新，并在本页标明日期。对需要告知或取得同意的变化，会依法通过适当方式说明。
