適用範囲

本ポリシーは、Sleeve Player（折页音乐）の iOS 版に適用されます。本アプリはローカル音楽プレーヤーであり、Sleeve Player 開発者が開発・維持しています。Android 版および第三者サービスには適用されません。

デバイス上で処理される情報

再生およびライブラリ管理のため、アプリはデバイス上で次の情報を読み取りまたは保存します：

  • 選択した音声ファイル、ファイル名とパス、曲名、アーティスト、アルバム、再生時間、アートワークおよび音声の技術情報（スキャン、表示、再生用）。
  • 同名の LRC ファイルおよび音声に埋め込まれた歌詞（歌詞表示と同期用）。オンライン歌詞検索は含まれません。
  • プレイリスト、お気に入り、キュー、再生位置、再生回数、最終再生時刻および最近の再生履歴（再生の再開とスマートリスト用）。
  • 外観、音響効果、スリープタイマー、歌詞オフセット、除外フォルダ、フォルダアクセス用ブックマーク、ライブラリ索引および音声分析キャッシュ。

開発者はこれらの情報をアプリ経由で自社サーバーへアップロードせず、広告やクロスアプリ追跡にも使用しません。再生統計は端末上で計算される機能データであり、開発者へ送信される利用分析ではありません。

ファイルアクセスとシステムサービス

アプリはシステムピッカーを通じて選択したファイルまたはフォルダにアクセスし、継続アクセスのためセキュリティスコープ付きブックマークを保存します。アプリのミュージックフォルダ設定で認可済みフォルダを削除できます。フォルダ認可の削除により、元のファイルが自動削除されることはありません。

バックグラウンドオーディオにより再生を継続できます。アプリは現在の曲メタデータ、アートワーク、再生進捗をシステムの「再生中」、ロック画面およびメディアコントロールに提供します。カメラ、マイク、位置情報、連絡先へのアクセスは要求しません。

ネットワーク、共有、第三者

現行の iOS 版には、オンライン歌詞リクエスト、開発者運営のクラウドライブラリ、広告、追跡、第三者分析 SDK は含まれません。ライブラリや再生履歴を開発者または広告サービスへ自動送信しません。

iCloud Drive または他のファイルプロバイダ内の音楽を選択した場合、iOS または当該プロバイダが設定と各ポリシーに従いファイルをダウンロードまたは同期する場合があります。デバイスのバックアップにアプリデータが含まれることもあります。本ポリシーはシステムサービスがネットワークを一切使わないことを意味しません。

ファイルを共有することを選択した場合、選択した受信アプリまたはサービスに渡されます。アプリのファイル削除機能を使うと、選択した元の音声ファイルが削除される場合があります。削除前に選択内容を確認してください。

保存期間、削除、管理

設定、索引、キャッシュ、プレイリストおよび再生履歴は、継続利用のためデバイス上のアプリデータ領域に保存されます。新しい再生が記録されると、最近の履歴は直近 90 日・曲あたり最大 200 件に整理されます。累計再生回数と最終再生時刻は引き続き保存されます。

アプリ内でプレイリストの編集、フォルダ管理、設定変更ができます。「App を削除」を選ぶとデバイス上のアプリとそのローカルデータが削除されます。「App をオフロード」では書類とデータが残ります。外部認可フォルダ内の音楽、共有済みのコピー、iCloud その他のバックアップは、アプリ削除だけではすべて削除されません。該当サービス側で別途管理してください。

開発者は、デバイス上にのみ存在するライブラリおよび再生データにリモートアクセスしたり、代わりに削除したりすることはできません。

サポート連絡で送信される情報

開発者へメールで連絡することを選んだ場合、メールアドレス、メッセージ、および任意で提供したスクリーンショットや診断情報は、返信、問題調査、またはプライバシー関連のリクエスト対応に使用されます。不要な個人情報や音楽ファイルは送らないでください。サポートのやり取りは、リクエストおよび必要なフォローアップの処理に必要な期間のみ保持されます。法的に保持が必要な場合を除き、削除を請求できます。

本ポリシーサイトの閲覧

本サイトは GitHub Pages でホストされています。広告、分析スクリプト、第三者フォント、開発者が設定する追跡 Cookie は埋め込まれていません。閲覧にサインインは不要です。

ホスティング提供者である GitHub は、自社ポリシーに基づき IP アドレスなどの必要なアクセスデータを処理します。これはアプリがデバイス上で処理する音楽データとは別です。GitHub プライバシー声明をご覧ください。

子どものプライバシー

本アプリはアカウント登録や分析サービスを通じて子どもの個人情報を収集せず、子どもの情報収集を目的としません。自発的に送ったサポート情報に子どもの個人情報が含まれると思われる場合は、開発者までご連絡ください。

ポリシーの更新

アプリの機能またはデータ取り扱いが変わる場合、本ポリシーは更新され、本ページに日付が表示されます。通知または同意が必要な変更は、法令に従い適切に伝えられます。
