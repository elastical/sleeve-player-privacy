隱私權政策

音樂留在你的裝置上。隱私說明，也應當清楚易讀。

更新及生效日期：2026-10-28

無需註冊帳戶。開發者不透過應用收集或上傳你的曲庫和播放記錄。

適用範圍在裝置上處理的資訊檔案存取與系統服務連網、分享與第三方保存期限、刪除與控制聯絡開發者時的資訊造訪本政策網頁兒童隱私政策更新聯絡方式

適用範圍

本政策適用於折頁音樂（Sleeve Player）的 iOS 版本。該應用是一款本地音樂播放器，由Sleeve Player 開發者開發和維護。本政策不適用於 Android 版本或第三方服務。

在裝置上處理的資訊

為實現播放和管理曲庫，應用會在裝置上讀取或儲存以下資訊：

資訊用途
音樂檔案和標籤讀取使用者選定的音訊檔案、檔名和路徑、歌名、歌手、專輯、時長、封面及音訊技術參數，用於掃描、展示和播放。
本地歌詞讀取同名 LRC 檔案或音訊內嵌歌詞，用於顯示歌詞和同步進度。不提供線上歌詞檢索。
播放及管理資料儲存歌單、收藏、佇列、播放位置、播放次數、最近播放時間和近期播放記錄，用於恢復播放及產生智慧列表。
偏好、授權和快取儲存外觀、音效、睡眠定時、歌詞偏移、排除目錄、授權目錄書籤，以及曲庫索引和音訊分析快取。

上述資訊不由開發者透過應用上傳至自有伺服器，也不用於廣告或跨應用追蹤。播放統計是在本機計算的功能資料，不是傳送給開發者的使用分析。

檔案存取與系統服務

應用透過系統檔案或資料夾選擇器存取你選擇的音樂，並儲存安全作用域書籤，以便後續繼續存取。你可以在應用的音樂資料夾管理中移除已授權目錄；移除目錄授權不會自動刪除該目錄中的原始檔案。

應用使用背景音訊能力繼續播放，並向系統「正在播放」、鎖定螢幕和媒體控制介面提供目前歌曲資訊、封面和播放進度。不請求相機、麥克風、定位或通訊錄權限。

連網、分享與第三方

目前 iOS 版本不包含線上歌詞請求、開發者自建雲端曲庫、廣告、追蹤或第三方統計 SDK。應用不向開發者或廣告服務自動傳送曲庫和播放記錄。

若你選擇 iCloud Drive 或其他檔案提供商中的音樂，iOS 或檔案提供商可能按需下載檔案或同步相關資料，這由你的系統設定及提供商政策決定。裝置備份也可能包含應用資料。本政策不表示系統服務永遠不會使用網路。

你主動使用分享功能時，所選檔案會交給你選擇的接收應用或服務。使用檔案刪除功能可能刪除你選定的原始音訊，請在操作前確認。

保存期限、刪除與控制

應用的設定、索引、快取、歌單及播放記錄保存在裝置的應用資料區域，以支援持續使用。近期播放記錄在新增記錄時按最近 90 天、每首歌最多 200 條整理；累計次數和最近播放時間會繼續保留。

你可以在應用內編輯歌單、管理目錄及修改設定。選擇「刪除 App」可移除裝置上的應用及其本地資料；「卸載 App」會保留文稿和資料。外部授權目錄中的音樂、你已分享的副本以及 iCloud 或其他備份不會因此全部刪除，請在相應服務中另行管理。

開發者無法遠端存取或代為刪除僅保存在你裝置上的曲庫與播放資料。

聯絡開發者時的資訊

若你主動透過電子郵件聯絡開發者，你的電子郵件地址、訊息及自願提供的截圖或診斷資訊會用於回覆、排查問題或處理隱私請求。請不要傳送不必要的個人資訊或音樂檔案。支援往來僅在處理請求及必要後續事項所需的期限內保留；你可以請求刪除相關往來，但依法需要保留的資訊除外。

造訪本政策網頁

本網頁由 GitHub Pages 託管，不嵌入廣告、分析指令碼、第三方字型或開發者設定的追蹤 Cookie。頁面內容不需要登入即可閱讀。

造訪網頁時，GitHub 作為託管服務商會按其政策處理必要的造訪資料（例如 IP 位址）。這與應用在裝置上處理音樂資料不同。詳情請參閱 GitHub 隱私權聲明。

兒童隱私

應用不透過帳戶註冊或分析服務收集兒童個人資訊，也不以收集兒童資訊為目的。如你認為主動傳送的支援資訊涉及兒童個人資訊，請聯絡開發者處理。

政策更新

功能或資料處理方式發生變化時，本政策會相應更新，並在本頁標明日期。對需要告知或取得同意的變化，會依法透過適當方式說明。

聯絡方式
